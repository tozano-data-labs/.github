# Obtenir de l'aide

- **Question d'usage ou de conception** : ouvrir une *Discussion* sur le dépôt concerné, sinon une issue.
- **Bug** : ouvrir une issue avec le formulaire « Bug ».
- **Problème de qualité de données** : formulaire « Qualité de données ».
- **Faille de sécurité** : voir [`SECURITY.md`](./SECURITY.md), jamais en issue publique.

Avant d'ouvrir une issue, vérifier qu'elle n'existe pas déjà et lire le `README` du dépôt.
