# Code de conduite

Cette organisation adopte le **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/)**.

En résumé : on échange de façon respectueuse et constructive, on accepte la critique de bonne foi, et on ne tolère ni harcèlement ni discrimination.

Signalement d'un comportement inapproprié : contactez privément un owner de l'organisation via [son profil GitHub](https://github.com/orgs/tozano-data-labs/people?query=role%3Aowner).
